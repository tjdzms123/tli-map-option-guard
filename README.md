# TLI 맵 옵션 가드

토치라이트: 인피니트의 맵(이계 스테이지) 왼쪽 **기본 옵션** 창을 화면에서 읽어서,
내가 못 도는 옵션이 붙어 있으면 **옵션 초기화** 버튼 위에 빨간 네모를 띄워 주는 Windows 프로그램입니다.

## 동작 방식

1. 게임 창이 맨 앞에 있을 때 0.5초마다 기본 옵션 영역을 캡처합니다.
2. Windows에 들어 있는 한국어 OCR로 글자를 읽습니다. 작은 빨간 글자도 잘 읽히도록 이미지를 확대하고 흑백으로 바꿉니다.
3. 본 옵션은 `collected_options.json`에 중복 없이 모아 둡니다.
4. 옵션이 많아 창을 내려야 다 보이는 맵은, 스크롤하며 본 옵션을 기억해 둡니다.
5. 지금 보이는 옵션이나 기억한 옵션에 금지 키워드나 거르기로 고른 옵션이 있으면, 초기화 버튼 위에 네모와 걸린 옵션을 표시합니다.
6. 네모는 클릭이 그대로 통과하므로 버튼을 눌러도 됩니다.

게임 메모리나 입력은 건드리지 않고 화면만 읽습니다.

## 요구 사항

- Windows 10 2004 이상 또는 Windows 11
- 빌드: .NET 10 SDK / 실행만: .NET 10 Desktop Runtime
- Windows 한국어 OCR: 한국어 언어 팩에 포함되어 있습니다. 없으면 실행할 때 안내 메시지가 뜹니다.
- 게임은 **창 모드** 또는 **테두리 없는 창 모드**여야 합니다. 전체 화면 전용 모드에서는 네모가 보이지 않을 수 있습니다.

## 빌드와 실행

```bash
dotnet run --project MapOptionGuard
```

exe 하나로 만들기:

```bash
dotnet publish MapOptionGuard -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -o publish
```

실행하면 메인 창이 뜹니다. 상태, 인식 결과, 설정이 모두 이 창에 있고, 창을 닫으면 프로그램이 끝납니다.
검사는 게임 창이 맨 앞에 있을 때만 하므로, 메인 창은 옆에 두거나 최소화해 두면 됩니다.

| 영역 | 내용 |
| --- | --- |
| 게임 창 | 찾을 창 제목·프로세스 이름과 연결 상태(프로세스, 게임 화면 크기) |
| 감시 | 중지/시작, 영역 설정, 검사 간격, 지금 상태(걸린 옵션) |
| 인식 결과 | 마지막으로 OCR이 읽은 글자, OCR에 넣은 이미지 보기 |
| 거르기 | 직접 키워드, 옵션 모으기 켜기/끄기, 거를 옵션 선택, 모은 개수 |
| 설정 파일 | config.json 열기, 다시 불러오기 |

## 처음 설정

1. 게임에서 맵 선택 화면을 열어 왼쪽 **기본 옵션** 창이 보이게 합니다.
2. 메인 창에서 **영역 설정...** 을 누릅니다.
3. 멈춘 게임 화면 위에서 두 번 드래그합니다.
   - 1단계: '기본 옵션' 제목부터 마지막 옵션 줄까지
   - 2단계: '옵션 초기화' 버튼
   - 우클릭은 이전 단계, Esc는 취소입니다.
4. 맵을 돌면서 옵션 창을 띄우면 옵션이 자동으로 모입니다. 거를 옵션은 아래 **옵션 모으기와 거를 옵션 선택**에서 고릅니다.

## 옵션 모으기와 거를 옵션 선택

맵 기본 옵션 전체 목록을 따로 구하기 어려워서, 쓰면서 본 옵션을 모아 두고 그중에서 고르는 방식입니다.

- 옵션 창이 열려 있으면, 두 번 연속 같게 읽힌 화면에서 처음 본 옵션만 기록합니다. 같은 창을 0.5초마다 다시 세지는 않습니다.
- 여러 줄로 줄바꿈된 옵션은 한 옵션으로 묶습니다. 글머리표(◆)나 앞 줄의 문장 끝(…다, %, 중첩, 지속)을 기준으로 나눕니다. 다만 `의 확률로 …`처럼 조사로 시작하는 줄은 앞 줄에 붙입니다.
- 드롭 수량 같은 맵 보상 줄은 거를 대상이 아니라서 모으지 않습니다. 이미 모인 것도 목록에서 뺍니다. 다른 보상 줄을 빼려면 `rewardKeywords`에 추가합니다.
- 띄어쓰기를 뺀 글자가 80%(`sameOptionSimilarity`) 이상 같으면 같은 옵션으로 보고 한 항목에 셉니다. 이미 따로 모인 비슷한 옵션도 실행할 때 하나로 합칩니다.
  - 거르기 판정도 같은 기준이라, 거르기로 고른 옵션과 80% 이상 비슷한 옵션이 보이면 네모를 띄웁니다.
  - 수치만 다른 옵션이나 `물리`/`부식`처럼 두어 글자만 다른 짧은 옵션도 같은 옵션으로 묶일 수 있습니다. 너무 많이 묶이면 `0.85`~`0.9`로 올립니다.
- 메인 창에서 **거를 옵션 선택...** 을 누르면 모은 옵션 목록이 열립니다.
  - 위쪽 검색창에 글자를 치면 띄어쓰기와 상관없이 걸러서 보여 줍니다.
  - 거를 옵션에 체크하면 바로 저장되고 다음 검사부터 적용됩니다.
  - **거르는 옵션만 보기**로 지금 거르는 옵션만 모아 볼 수 있습니다.
- 본 횟수는 대략값입니다. OCR이 흔들리면 같은 창이 두 번 세어질 수 있습니다.
- 줄 나누기가 틀려 옵션이 둘로 쪼개지거나 둘이 붙어서 모일 수 있습니다. 그럴 때는 메인 창 **직접 키워드** 칸에 짧은 키워드를 적는 방법도 같이 쓸 수 있습니다.

## 스크롤해야 보이는 옵션 기억

옵션이 많은 맵은 기본 옵션 창을 내려야 아래 옵션이 보입니다. 화면에 보이는 것만 읽으면 내린 뒤 위쪽 옵션을 놓치므로, 지금 옵션 창에서 본 옵션을 위에서부터 순서대로 기억합니다.

- 새로 읽은 화면이 기억한 목록과 두 개 이상 연달아 같은 순서로 겹치면 스크롤로 보고 이어 붙입니다. 창 가장자리에서 잘려 반만 보이던 옵션은 다 보이면 바꿔 넣습니다.
- 겹치지 않으면(옵션 초기화, 다른 맵) 기억을 지우고 새로 시작합니다. 일부 옵션만 바뀌어도 새로 시작합니다.
- 내려서 안 보이게 된 거를 옵션도 기억에 남아 있으면 네모를 띄웁니다. 메인 창 상태에 `기억한 옵션 N개`가 함께 나옵니다.
- 한 번에 끝까지 내려서 앞 화면과 겹치는 옵션이 없으면 다른 옵션 창으로 보고 위쪽 옵션을 잊습니다. 휠로 조금씩 내려 주세요.
- 옵션 초기화를 누른 뒤 0.5~1초 동안은 이전 옵션 기준으로 네모가 남아 있을 수 있습니다.

## config.json

exe와 같은 폴더에 처음 실행할 때 만들어집니다.

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| `windowTitle` | `Torchlight: Infinite` | 게임 창 제목. 정확히 일치해야 합니다. |
| `processName` | `torchlight_infinite` | 게임 프로세스 이름(.exe 제외). 같은 제목을 쓰는 TTD 같은 도구 창과 구분합니다. 비우면 확인하지 않습니다. |
| `intervalMs` | `500` | 검사 주기(ms). 200~5000 |
| `ocrScale` | `2.0` | OCR 전에 확대하는 배율. 1.0~4.0 |
| `fuzzyMatch` | `true` | 4글자 이상 키워드에 한해 OCR 한 글자 오인식을 허용합니다. |
| `panelAnchor` | `기본 옵션` | 이 글자가 보일 때만 옵션 창이 열린 것으로 봅니다. 비우면 항상 검사합니다. |
| `optionRegion` | 대략값 | 옵션 영역. 게임 화면 기준 비율(0~1)이며 영역 설정으로 저장됩니다. |
| `resetButtonRegion` | 대략값 | 초기화 버튼 영역. 영역 설정으로 저장됩니다. |
| `blockedKeywords` | `["실명", "마비"]` | 직접 적는 금지 키워드. 거르기로 고른 옵션과 함께, 하나라도 보이면 네모를 띄웁니다. |
| `rewardKeywords` | `["드롭 수량"]` | 맵 보상 줄의 키워드. 이 키워드가 든 줄은 거를 옵션 후보로 모으지 않습니다. |
| `sameOptionSimilarity` | `0.8` | 띄어쓰기를 뺀 글자가 이 비율 이상 같으면 같은 옵션으로 봅니다. 모으기·스크롤 기억·거르기 판정에 씁니다. 0.5~1.0 |
| `collectOptions` | `true` | 본 옵션을 `collected_options.json`에 모을지 여부 |
| `boxColor` | `#FF2020` | 네모 색 |
| `boxThickness` | `4` | 네모 두께(px). 1~20 |

영역 설정을 하면 config.json을 다시 저장하므로, 파일에 적어 둔 주석은 사라집니다.

## 키워드 고르는 법

- 메인 창 **인식 결과** 칸에서 실제로 읽힌 글자를 볼 수 있고, **OCR 이미지 보기**로 OCR에 넣은 이미지(`last_ocr.png`)를 열 수 있습니다.
- 읽힌 글자 중에서 그 옵션에만 있는 짧은 구절을 키워드로 씁니다. 예: `실명`, `마비`, `레이저`, `축복을4회상실`
- 띄어쓰기와 줄바꿈은 무시하고 비교하므로, 줄이 바뀐 옵션도 이어서 적으면 됩니다.
- 1~2글자 키워드는 다른 옵션에도 걸릴 수 있으니 주의하세요.

## 코드 구조

| 파일 | 역할 |
| --- | --- |
| `MainForm.cs` / `MainForm.Designer.cs` | 메인 창. 배치는 VS 디자이너(Designer.cs), 동작은 MainForm.cs |
| `OptionPickerForm.cs` / `OptionPickerForm.Designer.cs` | 거를 옵션 선택 창. 위와 같은 방식 |
| `CalibrationForm.cs`, `OverlayForm.cs` | 화면을 직접 그리는 창이라 디자이너 없이 코드로만 작성 |
| `OptionGuard.cs` | 게임 창 찾기 → 캡처 → OCR → 옵션 수집 → 거르기 판정(화면 없음) |
| `OptionScanner.cs` | 캡처 전처리(반전·밑줄 제거)와 Windows OCR |
| `OptionLineParser.cs`, `OptionCollector.cs`, `KeywordMatcher.cs` | 옵션 나누기, 모으기, 키워드·비슷한 옵션 비교 |
| `PanelOptionMemory.cs` | 스크롤하며 본 옵션 기억 |
| `GameWindow.cs` | 제목·프로세스·크기로 게임 창 고르기 |
| `SelfTest.cs` | 진단 모드 |

## 진단 모드

창을 띄우지 않고 옵션 영역을 한 번 읽어, 창 찾기·OCR·옵션 나누기·판정 결과를 텍스트 파일로 남깁니다.
이미 프로그램을 실행 중이어도 같이 돌릴 수 있고, 게임 창이 맨 앞에 없어도 화면에 보이기만 하면 읽습니다.

```bash
MapOptionGuard.exe --selftest selftest.txt
```

- 화면을 읽을 때 원본 캡처를 `selftest_raw.png`로 남기고, OCR에 넣은 이미지를 `selftest_ocr.png`로 남깁니다.
- 저장해 둔 캡처로 같은 화면을 다시 시험할 수 있습니다. OCR 처리를 고친 뒤 비교할 때 씁니다.

```bash
MapOptionGuard.exe --selftest selftest.txt --image selftest_raw.png
```

## OCR 처리

- RGB 중 가장 밝은 채널을 반전해, 흰·빨간·주황·하늘색 글자를 모두 밝은 배경 위 진한 글씨로 만듭니다.
- 밑줄 친 단어(약화, 마취 등)는 OCR이 통째로 놓치므로, 글자 획보다 긴 가로 줄은 지우고 읽습니다.
- OCR이 `%`를 `0/0`으로 읽는 것(`+180%` → `+1800/0`)은 숫자 뒤에 올 때만 `%`로 되돌립니다.

## 주의

- 네모 창은 화면 캡처에서 빠지도록 설정되어 있어 녹화나 스크린샷에는 보이지 않습니다. 자기 화면을 다시 읽어 키워드가 걸리는 것을 막기 위해서입니다.
- 화면만 읽는 방식이지만, 게임사 정책상 문제가 없다고 보장하지는 않습니다.
